# Научное Золотое кольцо — структура проекта и договорённости

VR-квест по Малому Золотому кольцу. Unity 6.2 (URP), VR / Oculus Quest 2 (standalone Android).
Файл — источник правды по структуре и правилам командной работы. Обновлять по мере изменений.

## Структура папок (Assets/_Project/)

- Scenes/
  - Core/      — боевые сцены: Bootstrap (постоянная, менеджеры), Lobby, Finale
  - Cities/    — боевые сцены городов (канонические имена, 1 владелец на сцену)
  - Quizzes/   — сцены викторин
  - _Sandbox/  — ЛИЧНЫЕ песочницы с префиксом имени: Eugen_..., Tanya_..., Oleg_...
- Scripts/
  - Core/       — GameManager, прогресс, загрузка сцен
  - Interaction/— хват, Socket Interactor, артефакты
  - Quiz/       — система викторин (data-driven)
  - Guide/      — робот-гид
  - UI/
- Prefabs/
  - Artifacts/  — 12 артефактов
  - Stands/     — стенд-подиум
  - Guide/      — робот
  - Interaction/
  - UI/
- Data/
  - Cities/     — ScriptableObject на каждый город
  - Quizzes/    — данные викторин
- Art/  Models/  Materials/  Textures/
- Audio/  Guide/  SFX/  Music/
- Settings/     — URP-ассеты, XR-конфиг

Префикс _Project держит наши файлы отдельно от импортированных со стоков ассетов.

## Правила командной работы

1. Личные/экспериментальные сцены — только в Scenes/_Sandbox/ с префиксом имени
   (Eugen_TestGrab, Tanya_QuizProto). Так сцены не затираются друг у друга.
2. Боевые сцены (идут в билд) — в Core/Cities/Quizzes с каноническими именами и одним
   владельцем на сцену. Без префиксов имён.
3. Никогда двое не открывают одну сцену одновременно — сцены Unity не мёрджатся.
4. Всё интерактивное — префабы. Правим префаб, а не копию в сцене.
5. Скрипты только в Scripts/... по папкам — чтобы при обмене пакетами пути совпадали.
6. Настройки проекта: Asset Serialization = Force Text, Version Control = Visible Meta Files.
7. Контроль версий: обмен .unitypackage — стопгэп (не переносит удаления/переименования).
   Цель — перейти на git или Unity Version Control.

## Ключевые технические решения

- Рендер: URP (шаблон Universal 3D). НЕ HDRP — Quest не тянет.
- XR: OpenXR + Meta Quest + XR Interaction Toolkit + Input System.
- Билд: Android standalone, IL2CPP + ARM64, текстуры ASTC. Цель 72 Гц.
- Управление: левая рука — предметы, правая — перемещение (телепорт). Часть викторин — обе руки.
- Артефакт при взятии клеится к левой руке.
- ГЕЙТ: сначала пустая VR-сцена встаёт на Quest и руки работают — потом контент.

## Архитектура игры

- Прохождение линейное: города открываются по очереди (город 2 доступен после викторины города 1).
- 1 город = 1 сцена. 2 объекта = 2 локации/зоны. Между объектами — возврат в лобби, артефакт на стенд.
- Викторина в конце города: 1 тестовая (data-driven) + 1 интерактивная. Без неё следующий город закрыт.
- Робот-гид (телевизор в руках, на колёсиках) ездит за игроком, на ТВ — диегетичный UI и 2 кнопки
  (в лобби / продолжить). В скриптовые моменты ходьба блокируется.
- Финал (в духе 1 главы Bendy): все артефакты на стендах -> загорается карта с замкнутым кольцом ->
  раздвижная дверь -> финальный тест со статистикой.
- Повторное прохождение БЕЗ перезапуска: GameManager делает полный сброс (закрыть города, очистить стенды).

### Критично технически
- Артефакт обязан пережить смену сцены: факт сбора хранит GameManager (persistent), физический
  предмет пересоздаётся по данным в лобби. НЕ полагаться на объект сцены — он уничтожится при загрузке.
- Переходы город<->лобби<->викторина частые: fade-to-black, лобби/менеджеры в постоянной сцене (additive).
- Интерактивные викторины свести к 2–3 переиспользуемым шаблонам (сборка из деталей; запуск физэффекта),
  рескинить под города — не делать 6 уникальных мини-игр.

## Реализовано на 28.09.2026 (as-built; подробности — в DEV_PROGRESS, раздел СЛЕПОК АРХИТЕКТУРЫ)

- Ядро: GameManager (прогресс/сброс) + SceneLoader (additive-переходы, fade, перенос рига в SpawnPoint, RestartToLobby). Bootstrap — постоянная сцена со всей инфраструктурой; контентные сцены = окружение + SpawnPoint + интерактив (без рига/менеджеров).
- Риг вынесен в постоянный префаб Prefabs/Interaction/PlayerRig.prefab. Хват — левая рука (interaction-слой Default), маркеры карты — обе руки (слой Map); правая рука артефакты не берёт.
- Fade — чёрная сфера на камере (компонент ScreenFader). Длительность/цвет настраиваются на компоненте, не в шейдере.
- Артефакт полностью data-driven: ArtifactSceneSpawner в каждой сцене раскладывает единственный артефакт по состоянию GameManager (стенд / левая рука / подставка своего города). StickyArtifact запрещает ронять мимо стенда.
- Лобби: карта городов (CityMarker + общий попап MapController -> SceneLoader.GoToCity; закрытые города = надпись Скоро по IsCityUnlocked) + кнопка Перезапуск (полный сброс под fade).
- Русский UI — TMP-шрифт Assets/_Project/Art/Fonts/Arial SDF.asset (дефолтный шрифт кириллицу не содержит).
- Готов только Ярославль (City_Yaroslavl + данные). Остальные 8 городов закрыты и без сцен — добавлять по мере наполнения (клонировать City_Yaroslavl, задать citySceneName/artifactPrefab в CityData).
