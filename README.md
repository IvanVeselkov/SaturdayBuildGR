# Научное Золотое кольцо — VR тур-квест

VR-приложение для Всероссийского хакатона **«ИТ-Прорыв»**, номинация **«Виртуальная и дополненная реальность»**, кейс **«Научное Золотое кольцо»** (Varwin).

Игрок — участник научной экспедиции «Собери Научное кольцо». В каждом из 9 городов Малого Золотого кольца он посещает объект научной инфраструктуры, слушает робота-гида EVE, **ищет научный артефакт**, проходит **мини-викторину** и привозит артефакт в лобби. Когда на стендах собраны все 9 артефактов, маршрут на карте замыкается в золотое кольцо, открывается дверь в финальный зал с итоговой статистикой.

## Запуск

### Из редактора Unity
1. Установите **Unity 6000.5.3f1** через Unity Hub (модуль *Windows Build Support (IL2CPP)*).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/IvanVeselkov/SaturdayBuildGR
   ```
3. В Unity Hub: **Add → Add project from disk** → выберите папку `src`.
4. Дождитесь импорта ассетов (первый запуск может занять несколько минут).
5. Откройте сцену **`Assets/_Project/Scenes/Core/Bootstrap.unity`**.
6. Подключите HTC Vive и запустите SteamVR (или включите XR Interaction Simulator для проверки без шлема, см. выше).
7. Нажмите **Play** — игра автоматически загрузит лобби.

> Важно: запускать игру нужно **только со сцены `Bootstrap`**. В ней находятся постоянные системы (GameManager, SceneLoader, XR-риг, EventSystem); остальные сцены подгружаются поверх неё.

### Сборка под Windows
1. **File → Build Profiles** → платформа **Windows** (x86_64).
2. Убедитесь, что в списке сцен первой (index 0) стоит `Core/Bootstrap`, затем `Core/Lobby`, сцены городов `Cities/City_*`, викторин `Quizzes/Tanya_*` и `Core/Finale`.
3. **Edit → Project Settings → XR Plug-in Management → Windows**: включён **OpenXR**.
4. **Build** → запустите полученный `GoldenRing.exe` при запущенном SteamVR.

## Игровой процесс

1. **Лобби** — карта-маршрут Золотого кольца. Доступен только текущий город (жёлтый маркер); пройденные города отмечаются зелёным, между ними прокладывается путь.
2. **Город** — робот-гид **EVE** встречает игрока у объекта и ведёт по экспозиции с озвученным рассказом. Артефакт становится доступен только после рассказа — его нужно **найти** и взять правой рукой.
3. **Викторина** — игрок кладёт артефакт в держатель: тест по услышанному + интерактивное испытание. Пока испытание не пройдено, артефакт заблокирован в держателе.
4. **Возврат в лобби** — забрав артефакт из держателя, игрок попадает в лобби и ставит его на подиум своего города. Открывается следующий город.
5. **Финал** — после 9-го артефакта маршрут на карте замыкается в золотое кольцо, поднимается дверь в финальный зал. Итоговый экран: **время прохождения, количество ошибок и медаль** (золото / серебро / бронза).
6. **Повторное прохождение** — кнопка «Пройти заново» сбрасывает весь прогресс **без перезапуска приложения**.

### Форматы викторин
Тест с вариантами ответа, сборка Солнечной системы, «поймай толчок» на сейсмографе, расстановка шагов алгоритма / эксперимента по порядку, сопоставление, сборка сруба из брёвен и др. — **больше 3 разных форматов** на маршруте.

## Структура репозитория

```
/
├── README.md
└── src/                         # Unity-проект (открывать в Unity Hub)
    ├── Assets/
    │   └── _Project/            # весь код и контент команды
    │       ├── Scenes/
    │       │   ├── Core/        # Bootstrap, Lobby, Finale
    │       │   ├── Cities/      # City_* — сцены городов
    │       │   └── Quizzes/     # Tanya_* — сцены викторин
    │       ├── Scripts/
    │       │   ├── Core/        # GameManager, SceneLoader, ScreenFader, финал
    │       │   ├── Guide/       # EvaZoneGuide — робот-гид EVE
    │       │   ├── Interaction/ # артефакты, стенды, держатели, карта
    │       │   └── Quiz/        # механики викторин
    │       ├── Prefabs/         # артефакты, стенды, EVE, XR-риг
    │       ├── Data/            # ScriptableObject городов (CityData, GameConfig)
    │       ├── Art/             # модели, материалы, текстуры, шрифты, UI
    │       └── Audio/           # озвучка гида, звуки
    ├── Packages/
    └── ProjectSettings/
```

### Архитектура
- **Постоянная сцена `Bootstrap`** хранит все системы; контентные сцены (лобби, города, викторины, финал) загружаются additive поверх неё с переходом через затемнение.
- **`GameManager`** — единственный источник правды о прогрессе: открытые города, собранные/поставленные артефакты, пройденные викторины, ошибки и время. Полный сброс — `ResetProgress()`.
- **Data-driven города**: каждый город описан ассетом `CityData` (сцены, артефакт, порядок). Новый город добавляется данными, без правки кода.
- **Артефакт переживает смену сцены**: физический объект пересоздаётся `ArtifactSceneSpawner` по состоянию `GameManager` (в руке / в держателе / на подиуме).
- **Робот-гид EVE** (`EvaZoneGuide`) — зонно-триггерный гид: рассказ запускается, когда игрок входит в зону экспоната.
